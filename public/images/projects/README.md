# Project screenshots

Drop screenshots here and reference them from `src/data/projects.js` via a root-relative
path, e.g. `/images/projects/responsepro.png`.

Expected filenames based on the current entries in `data/projects.js`:

- `responsepro.png`
- `shermlandscaping.png`

If an image is missing, `ProjectCard` falls back to a styled placeholder panel automatically —
so it's safe to add project entries before the screenshot exists.
